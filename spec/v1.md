## Purpose

This document freezes the SA-0 reference contract. It describes canonical bytes and exact field surfaces; it does not claim a production listener, filesystem, cache, installer, parser, or application bridge.

> A field absent from this document is rejected. Pair bearer `secret` is valid only on the Pair URL object. Receiver cache and merged views are never producer inputs.

## CanonicalJsonV1

| Property | Exact v1 rule |
|---|---|
| Encoding | UTF-8 without BOM or whitespace |
| Object keys | Strict UTF-8 byte order; duplicate and unknown typed fields rejected |
| Strings | NFC; shortest JSON escapes for `"`, `\\`, and U+0000–001F; other Unicode emitted directly |
| Numbers | Signed or unsigned canonical decimal integers only; no `+`, leading zero, `-0`, exponent, NaN, infinity, or float |
| Decode | Strict parse, typed decode, canonical re-encode, constant-time byte comparison |
| Public API | `CanonicalJsonV1::encode`, `decode`, and `decode_value` in `src/canonical.rs` |

## Wire and frame registry

| Registry | Value |
|---|---|
| Peer protocol | `1` |
| Report schema | `1` |
| State schema | `1` |
| Logical frame | `1` |
| Control | `1` |
| Consent scope | `usage.aggregate.read.v1` |
| Aggregation | `1` |
| TZDB | `2026c` |

Each Noise transport message is `u32be(ciphertextLen) || NoiseCiphertext`. The ciphertext maximum is 61,456 bytes. The authenticated plaintext frame has a 38-byte header and a 61,440-byte maximum.

```text
magic[4] = "SYR1"
frameVersion:u16be = 1
kind:u8 = 1 request | 2 response | 3 error
flags:u8 = bit0 final; all other bits zero
requestId[16]
chunkIndex:u32be
chunkCount:u32be
payloadLen:u32be <= 61,402
reserved:u16be = 0
payload[payloadLen]
```

| Kind | Count and ordering | Payload and logical cap |
|---|---|---|
| Request | One chunk; index 0; final set | 61,402 bytes |
| Error | One chunk; index 0; final set | 4,096 bytes |
| Response | 1–274 contiguous chunks; only last is final | 61,402 bytes per chunk; 16,777,216-byte logical body |

| Command ID | Name | Exact body | Success data |
|---:|---|---|---|
| 1 | `status` | `{}` | Status object from the surface table |

| 3 | `offerCancel` | `{offerId}` | `null` |
| 4 | `pendingList` | `{}` | Pending-list items sorted by `pendingId` |
| 5 | `approve` | `{pendingId,sasGeneration}` | `null` |
| 6 | `reject` | `{pendingId,sasGeneration}` | `null` |
| 7 | `revoke` | `{grantId}` | `null` |
| 8 | `listenConfigure` | `{bindHost,bindPort}` | `null` |
| 9 | `shutdown` | `{}` | `null` |

Result `ok=0`; errors are `invalid=1`, `unauthorized=2`, `expired=3`, `revoked=4`, `busy=5`, `incompatible=6`, `unsafeState=7`, and `internal=8`. Error data is always `null`. `scanStatus` is `never`, `ok`, or `error`; `sourceFamilies` is sorted and unique with at most 128 entries.

### Pair URL

The canonical grammar is ASCII `syrtis://pair?offer=<lowercase-hex>`. Decoded hex is a CanonicalJsonV1 Pair URL object no larger than 4,096 bytes. Raw paste is capped at 16,384 bytes and the decoded URL at 8,192 bytes. Host accepts only canonical IPv4, canonical compressed IPv6, or lowercase LDH hostname. Port is 1024–65535 and expiry is in the next 1–900,000 milliseconds.

### Cache files

Each producer or receiver entry contains one CanonicalJsonV1 metadata object and one exact canonical response body. The filename is lowercase `SHA-256(cacheKeyJson)`. Producer and receiver roots cannot cross-read. Body hash validation precedes typed decode.
